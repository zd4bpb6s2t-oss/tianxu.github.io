# 太虚问道 · 手机版（iPhone / iOS Safari）
适用于苹果手机游玩，功能与 Windows 桌面版完全一致（自动战斗、AI 众生、法宝、万妖塔、悬赏、世界频道等）。

## 一、把游戏装到 iPhone 上（3 选 1）

### 方式 A：电脑局域网直连（最简单）
1. 在电脑上把这个文件夹用任意静态服务器托管（或用我启动的局域网服务）。
2. 手机与电脑连**同一个 Wi-Fi**。
3. 手机 Safari 打开地址：`http://<电脑局域网IP>:<端口>/index.html`
   （局域网 IP 例：192.168.1.8；具体以电脑实际 IP 为准）
4. 打开后点击 Safari 底部「分享」按钮 → 「添加到主屏幕」，即可全屏像 App 一样游玩，自动存档会保留在手机上。

### 方式 B：传到任意静态托管
把本文件夹上传到 GitHub Pages / Vercel / Netlify / 任意 Nginx 静态站，
手机 Safari 打开对应网址后，同样「添加到主屏幕」即可。

### 方式 C：AirDrop / 文件 App（离线单机）
把整个文件夹 AirDrop 到手机「文件」App，但 iOS 无法直接双击打开 HTML，
仍需配合一个本地静态服务器（如 App 内浏览器），因此推荐方式 A / B。

## 二、手机操作说明
- **主画面**：非战斗显示修为进度；进入战斗自动切到战斗场景。
- **自动战斗**：默认开启，无需反复点开关；野外/爬塔胜利后自动连打下一场。
- **世界频道**：点昵称看道友资料；**长按昵称 0.5 秒自动 @** 点名搭话。
- **GM 控制台**：点右下角「GM」按钮 → 密码 `admin`（F10 仅电脑有效）。
- **存档**：自动保存在手机 Safari，切后台时自动保存，关闭后重开进度不丢。

## 三、与桌面版差异
- 界面为手机竖屏适配（大按钮、双列技能、顶部吸附导航），支持 iPhone 刘海安全区。
- 仅前端单机 Demo；正式联机版需服务器。
